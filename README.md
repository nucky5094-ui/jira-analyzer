# Jira Cycle Time Analyzer

Локальное приложение для анализа CSV-выгрузки Jira.

## Что делает первая версия

- загружает CSV;
- проверяет поля `Issue Type`, `Created`, `Resolved`;
- рассчитывает время закрытия как `Resolved - Created`;
- переводит время в количество полных 24-часовых суток;
- фильтрует задачи по `Issue Type`;
- показывает частотную столбчатую диаграмму;
- позволяет выбрать отображение до 30 дней, до 90 дней или всех задач;
- показывает количество задач и долю при наведении;
- позволяет скачать диаграмму в PNG.

## Запуск

Откройте Terminal в PyCharm в папке проекта и выполните:

```bash
python -m pip install -r requirements.txt
```

После установки библиотек:

```bash
python -m streamlit run app.py
```

Streamlit откроет приложение в браузере.

Если браузер не открылся автоматически, в терминале будет локальный адрес вида:

http://localhost:8501

## Важно

Диапазон «До 30 дней» или «До 90 дней» меняет только отображение графика.
Задачи за пределами диапазона не удаляются из исходных данных.

Если отдельная кнопка скачивания PNG не сработает из-за Kaleido,
наведите курсор на диаграмму и используйте значок камеры в панели Plotly.
